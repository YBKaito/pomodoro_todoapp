# Focus Dock for Windows

Download Focus-Dock-1.1.0-Windows.exe using the file's Raw / Download button, then run it. Windows x64. No installer needed. This build is unsigned and may trigger a Windows publisher warning. It has not been run on Windows yet.

The mini sticky note stays above normal windows. Tasks and timer progress save locally. A running or paused focus session prevents closing the mini window; return to Main app and use Stop / reset to unlock.

Source: the main branch of this repository. A tagged release workflow is also included there.
